**Everything in this archive is invented.** There is no Free City of Meridian
Hollow, no Bureau of Sunlight, no Carrow Ridge, no Halcyon Mirrorworks and
nobody named in any of these pages. The collection is a worked example built
by `demo/build-demo.py` in the [Stackroom
repository](https://github.com/igor-vuta/stackroom), written so that a tool
for handling other people's disclosures can be demonstrated on a disclosure
that hurts nobody.

It answers the invented request BOS-2018-0117: four documents — an award
memorandum, correspondence, an evaluation record and a scanned annexe — with
redactions of every size, a page withheld end to end, three pages never
produced at all, a page in Russian, and one honest false positive left by an
open scanner lid. An earlier release of the same file, one review decision
older, is what the comparison section compares against.
