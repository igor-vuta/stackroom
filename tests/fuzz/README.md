# tests/fuzz

A small, dependency-free fuzz harness for the ingest pipeline.

`atheris` and `hypothesis` are not used: neither installs cleanly in the
environment this project's CI runs in, and the interesting inputs here are
*structured* — a `/Count` that lies, a `/CropBox` that disagrees with the
`/MediaBox`, an incremental update that keeps the previous revision — which a
byte-level fuzzer reaches only by luck. So the corpus is generated by hand from
a list of structural hazards, and then byte-mutated on top of that.

## What it asserts

Only three things, and deliberately nothing about correctness:

1. **It never hangs.** Every case runs in a child process under a wall-clock
   budget. A case that has to be killed is a failure.
2. **It never crashes with an unhandled traceback.** A `RuntimeError` the
   pipeline documents and catches is fine. A `UnicodeEncodeError` out of
   `SiteBuilder.write` is not.
3. **It never writes outside the output directory.** The input folder, the
   working directory and a tree of canary files are hashed before and after
   every case.

Anything else — whether the page was read correctly, whether a redaction was
found — is a job for `tests/test_pipeline.py` and `tests/test_redaction.py`.

## Running it

```
pytest tests/fuzz                        # the CI smoke run: ~40 cases, ~60 s
python tests/fuzz/harness.py --list      # what the corpus contains
python tests/fuzz/harness.py --seconds 600        # a soak, random seeds
python tests/fuzz/harness.py --seed 1234 --cases 200
python tests/fuzz/harness.py --case cropbox-mismatch --keep   # reproduce one
```

Every case is reproducible from `(name, seed)`, which is printed on failure
together with the path to the file that caused it. `--keep` leaves the
generated corpus and the output directory on disk so it can be opened.

## Adding a hazard

Add a generator to `corpus.py`. A generator takes a `random.Random` and returns
`(filename, bytes)`; it is registered by decorating it with `@hazard("name")`.
Keep the file small — the point is the shape, not the size — and write one
sentence saying what a real producer would have to do to emit it.
